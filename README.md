# CyberShield - Data Breach Response Simulator

A Python OOP cybersecurity project that simulates defensive data-breach incident management.

## Features

- Create and classify breach incidents
- Track affected records and exposed data
- Calculate a risk score
- Assign Low/Medium/High/Critical severity
- Track incident status
- Maintain an incident timeline
- Generate incident reports

## OOP Concepts

- Classes and objects
- Inheritance
- Polymorphism
- Abstraction
- Encapsulation
- Composition
- Exception handling

## How to Run

Python 3 is required.

```bash
python main.py
```

No third-party packages are required.

## Safety

This project uses simulated/synthetic breach information. It does not perform real credential theft, database dumping, exploitation, or unauthorized scanning.
